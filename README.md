# 펫노트 | 소프트웨어공학 학기 프로젝트

펫노트는 가족이 반려동물의 급여·산책·체중 기록과 돌봄 일정을 함께 관리하는 웹 서비스입니다.

개인정보가 포함된 기존 저장소를 삭제하고, 개인정보와 개인 작업 파일을 제외한 프로젝트 소스를 이 블로그 저장소의 `main` 브랜치로 옮겼습니다.
