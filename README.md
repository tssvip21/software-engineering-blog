# 반려동물 돌봄 관리 서비스

## 1차 초안 완성본

사용자와의 기획 논의를 바탕으로 20개 돌봄 모듈, 방별 권한·초대, 공통 활동 기록·루틴, 제품 영양 계산, 모듈별 통계와 통합 상태 화면을 로컬 서버와 연결했습니다. 실제 구글 OAuth 자격증명을 넣은 실계정 연동은 아직 확인하지 못했습니다. 현재 버전은 로컬 실행을 검증한 1차 초안이며, 외부 서비스 배포는 하지 않았습니다.

- 화면 검토: `START_DEMO.cmd` → `http://127.0.0.1:8001` (별도 시연 DB·시연 계정)
- 실제 기록 환경: `START_LOCAL.cmd` → `http://127.0.0.1:8000` (구글 인증 설정 필요)

## 기획 단계 기록 — 2026년 11월 2일

소프트웨어공학 수업 프로젝트 저장소입니다. 개인이나 여러 사람이 다양한 반려동물의 돌봄 정보를 기록하고, 통계와 종합적인 상태 확인을 통해 체계적으로 관리하는 웹 서비스를 기획합니다.

돌봄 기록이 체계적으로 모이지 않으면 관리 현황과 변화를 파악하기 어렵습니다. 여러 사람이 함께 돌볼 때는 정보 공유 부족으로 중복과 누락도 생깁니다. 필요한 모듈에서 기록한 정보를 한곳에 모아, 현재 상태와 기간별 변화를 확인하고 공동 돌봄의 정보 공유 문제도 해결합니다.

이번 학기 구현 범위는 두 가지입니다.

- **사용자:** 개인·공동 사용을 지원하고, 필요한 모듈을 선택·배치해 돌봄 정보를 쉽게 기록하고 관리합니다. 가족·친구·동거인은 공동 사용의 예시입니다.
- **반려동물:** 종·체격 등 기본 분류를 설정하고, 모듈에서 수집한 정보를 분류별 기준에 따라 통계와 종합 상태 확인에 활용할 수 있는 틀을 구축합니다. 리트리버·푸들 같은 세부 품종보다 소형·중형·대형 정도의 기본 분류를 우선하며, 분류 항목과 기준은 동물 종류에 맞춰 둡니다.

2026년 11월 2일 기준 기획 단계입니다. 기능은 구현 전이며 서비스 이름과 기술 스택, 분류별 수치 기준은 아직 정하지 않았습니다. 분류별 기준은 적용 대상과 출처를 확인한 항목부터 등록할 수 있도록 설계합니다.
