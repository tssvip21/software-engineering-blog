# 블로그 원본과 게시글

게시된 글의 원본은 [블로그 저장소](https://github.com/tssvip21/software-engineering-blog)의 `posts/`에서만 관리합니다. 이 프로젝트의 `blog/posts/`에는 본문 대신 포인터만 둡니다.

| 글 | 게시글 | 원본 |
| --- | --- | --- |
| 1편: 주제 선정과 구현 범위 | [읽기](https://tssvip21.github.io/software-engineering-blog/posts/01-topic-proposal.html) | [Markdown](https://github.com/tssvip21/software-engineering-blog/blob/main/posts/01-topic-proposal.md) |
| 2편: 데이터 설계와 ERD | [읽기](https://tssvip21.github.io/software-engineering-blog/posts/02-data-design.html) | [Markdown](https://github.com/tssvip21/software-engineering-blog/blob/main/posts/02-data-design.md) |
| 3편: 첫 배포 | [읽기](https://tssvip21.github.io/software-engineering-blog/posts/03-first-deployment.html) | [Markdown](https://github.com/tssvip21/software-engineering-blog/blob/main/posts/03-first-deployment.md) |

`drafts/`에는 공개 글에 없는 초기 초안·개발 메모·피드백을 보존합니다. 이 자료는 최신 게시본이 아닙니다. 관련 첨부는 `assets/`에 남깁니다.

게시글을 고칠 때는 위 원본을 수정하고 본문을 메인 프로젝트에 다시 복사하지 않습니다. 주차별 글의 내용·날짜·게시 이력은 이번 저장 위치 정리로 바꾸지 않습니다.
