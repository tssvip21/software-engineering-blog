# [개선 14] 펫노트로 이름을 바꾸고 화면을 다시 칠하기

> 2026-11-18 로컬 초안. 사용자 검토 전이며 게시하지 않았다.

## 무엇이 불편했나

서비스 이름을 테일리에서 펫노트로 바꾸면서 화면도 다시 보기로 했다. 그동안 단계마다 스타일 파일을 하나씩 덧대다 보니 스타일 시트가 9장 쌓였다. 같은 버튼이 화면마다 조금씩 달랐고, 카드마다 "오늘 완료한 기록이 없어요" 같은 문장이 반복됐다. 걱정을 덜어 주려고 붙인 설명("~는 아니에요", "~는 그대로예요")도 화면 곳곳에 남아 있었다. 기능은 맞게 동작했지만, 처음 보는 사람에게는 꽉 차고 기계가 쓴 듯한 화면이었다.

이번 개선은 화면만 다뤘다. 저장 방식, 계산, 권한 같은 서버 쪽 코드는 바꾸지 않았다.

## AI가 낸 안과 내가 고른 것

AI에게 다른 서비스 10곳의 첫 화면을 캡처해서 글자 크기, 간격, 색을 비교하게 했다. 공동 육아 기록 앱, 할 일 앱, 노트 앱, 국내 디자인 시스템 문서 등을 봤다. 두 곳은 첫 화면이 영상뿐이거나 봇 확인 화면이 떠서 다른 곳으로 바꿨다.

- **첫 시안**: 종이색 바탕에 노란 형광펜 강조를 썼다. 노란 기가 많고 화면이 꽉 차 보여서 다시 하게 했다.
- **두 번째 시안**: 여백을 넓히고 카드 정보를 네 줄로 줄였다. 짜임은 좋았지만 세 가지 색 시안이 모두 누렇게 보였다.
- **세 번째 시안**: 사이드바를 상단 탭으로 바꾸고 반려동물 머리띠를 세운 과감한 안이었다. 오히려 두 번째 짜임이 낫다고 판단해 되돌렸다.
- **최종**: 두 번째 짜임에 차가운 회백 바탕, 먹색 글자와 버튼, 초록 선택 표시를 골랐다. 노랑은 로고 책갈피에만 남겼다.

로고는 AI가 그린 세 안 중 "귀 달린 기록장"을 골랐다. 수첩 윗변에 귀 두 개와 책갈피가 있어 '펫'과 '노트'가 한 모양에 들어간다. 아이콘도 같은 굵기로 다시 그렸다. 반짝이 모양이던 위생은 비눗방울로, 김이 나던 밥그릇은 사료 그릇으로, 걷는 사람이던 산책은 발자국으로 바꿨다.

## 막혔던 것

- 처음에는 새 스타일을 '오늘' 화면에만 입혔다. 공통 틀은 모든 화면이 같이 쓰기 때문에, 다른 화면의 옛 스타일과 부딪히지 않게 새 스타일 파일을 화면별로 바꿔 끼우는 방식을 썼다.
- 모든 화면으로 넓힐 때는 실제로 열리는 화면 160개를 돌며 쓰이는 클래스를 모았다. 그중 188개가 새 스타일에 없었고, 화면별로 채웠다.
- 템플릿 72개 중 22개는 어떤 주소에서도 그려지지 않았다. 아무 데서도 부르지 않는 5개만 지우고, 코드가 이름을 부르는 나머지는 남겼다.
- 루틴 입력의 요일 선택이 라벨 안에 라벨이 들어간 잘못된 구조였다. 요일을 알약 모양 선택지로 다시 짰다.
- 옛 문장과 옛 스타일 파일 이름을 그대로 찾는 자동 검사 7개가 실패한다. 화면 동작이 깨진 것은 아니고, 검사가 바뀐 문장을 따라오지 못한 것이다. 검사 기대값을 고치는 일은 따로 남겼다.

## 확인한 것과 남은 것

Chromium에서 PC(1440px)와 모바일(390px)로 화면 묶음 42개를 모두 찍었다. 가로 넘침과 콘솔 오류는 없었다. 기록 버튼, 직접 입력 창, 루틴 완료, 반려동물 바꾸기, 모바일 메뉴는 직접 눌러 봤다. 실제 아이폰 Safari와 Firefox는 아직 보지 않았다. 첫 화면 히어로는 다음에 따로 다듬기로 했다.
