# 색을 바꾸는 것과 화면을 다시 만드는 것

5차 첫 개선을 확인한 사용자는 오늘 화면은 달라졌지만 돌봄 기능과 전체 기능 설정은 예전과 비슷하다고 지적했다. 앞선 작업은 기존 PC 배치의 장점을 유지한다는 조건을 너무 보수적으로 해석했다. 최근 기록 한 줄과 색을 더한 것을 전체 UI 재설계와 가깝게 보고한 점도 고쳐야 했다.

이번에는 외부 다종 기록 서비스의 구성과 사용 흐름을 더 참고했다. 왼쪽 탐색 위치는 유지하되 그 안의 정보와 조작을 다시 나눴다. 돌봄 기능은 실제 수치나 최근 내용을 읽고 바로 입력하는 카드로 바꾸고, 기능 설정은 사용 카드를 배치하는 보드로 바꿨다. 모든 기능의 목록은 필요할 때 열도록 분리했다. 오늘에 표시할 카드를 그 자리에서 바꾸고 미리 볼 수 있게 했다.

색도 분류 전체에 넓게 칠하는 방식에서 벗어났다. 큰 바탕과 일반 문자는 차분하게 두고 기능 아이콘·핵심 수치·선택 상태에 의미를 나눴다. 본문과 제목은 Pretendard, 큰 숫자는 Manrope를 사용했다. 두 서체 모두 출처와 라이선스를 확인해 자체 서버에서 제공하고, 실패했을 때 시스템 서체로 읽히도록 했다.

카드를 격자로 바꾸면서 세로 목록용 드래그를 그대로 쓸 수 없었다. 카드가 이동하며 주변 칸이 바뀌는 상황을 고려해 시작할 때의 배치 칸을 기준으로 좌우·상하 이동을 처리했다. 키보드와 기능/순번 선택 방식도 함께 유지했다. 기능 목록창에서는 Tab 초점이 밖으로 빠지는 문제가 실제 검사에서 발견돼 창 안 순환과 닫은 뒤 초점 복귀를 추가했다.

검사는 기록 보존과 권한, 빠른 입력, 저장 실패와 두 탭 충돌까지 실제 브라우저로 이어서 했다. 통과한 검사 수와 별개로, 카드가 늘어 일부 화면은 길어졌다. 기능 수가 많을 때는 분류·검색·내 그룹으로 좁혀 보는 흐름이 필요하다. 실제 보호자의 선호나 작업 시간을 측정한 것은 아니므로 이번 결과는 사용자가 직접 확인할 로컬 검수본으로 남긴다.
