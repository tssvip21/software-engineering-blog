# [개선 기록] 테일리 — 단색 테마에서 정보의 역할이 보이는 화면으로

> 2026-11-09 · AI 작성 초안 · 사용자 검토 전 · 로컬 작업 기록

## 남겨 둘 것과 바꿀 것

사용자는 현재 PC 사이트의 위치·배열은 괜찮은 부분이 있지만, 밝은 초록색 계열로 비슷한 네모가 반복되는 인상은 별로라고 했다. 그래서 전체를 모바일 화면처럼 다시 만드는 대신, 기존 PC 탐색과 다열 구성은 유지하면서 카드와 수치·색상의 역할을 바꾸는 방향으로 정했다. 외부 서비스의 구성과 사용 흐름, 정보 시각화 연구와 접근성 지침을 함께 참고했다.

## 색만 칠하지는 않았다

먹이·체중, 활동·휴식, 상태·건강, 생활·환경을 이름과 아이콘, 색으로 함께 구분했다. 공통 버튼은 파랑으로 통일하고 분류에 따라 다른 포인트 색을 사용했다. 오늘 화면에서는 완료 기록 건수와 루틴 완료를 구분하고, 자주 쓰는 기능에는 실제 수치와 단위를 보여주도록 했다.

이 과정에서 숫자를 크게 보여주는 것만큼 설명이 중요했다. 먹은 양을 모르는 기록은 제공량 기준 예상 열량이고, 물을 갈아 준 것은 음수량이 아니다. 과거 체중을 보여줄 때도 오늘 측정한 것처럼 보이지 않도록 날짜를 붙였다. 기존 통계 규칙을 바꾸지 않고 표시용 함수를 별도로 두었다.

최근 변화에서는 핵심 결론을 먼저 읽고, 필요한 날짜와 값을 펼치게 했다. 비교 범위를 정상 범위처럼 보이게 하는 게이지나 새 건강 점수는 넣지 않았다.

## PC와 모바일은 같지 않았다

PC는 기존 왼쪽 메뉴와 다열을 유지했다. 모바일에는 자주 쓰는 다섯 화면으로 이동하는 하단 탐색을 추가했다. 메뉴나 입력창과 초점이 겹치지 않는지, 기록 후에 선택했던 분류와 검색이 남는지도 확인했다.

기능 순서 변경은 드래그 외에 기능과 순번을 선택하는 대체 조작을 붙였다. 키보드 지원과 별개로 마우스·터치에서 잡아 끌지 않고도 작업을 끝낼 수 있도록 하기 위해서다. 이전에 제거한 위·아래 화살표를 모든 항목에 다시 붙이지는 않았다.

## 검사에서 다시 확인한 것

첫 터치 검사에서는 고정된 하단 메뉴 아래에 손잡이가 놓인 상태로 눌렀다. 화면의 실제 터치 대상을 확인한 뒤 검사 위치를 바로잡았고, 제품에도 포커스 스크롤 여유와 드래그 중 하단 탐색 처리를 보완했다. 검사 도구의 스타일시트 콜백 오류는 제품 보안 설정을 낮추지 않고 도구에서 수정했다.

공동 사용에서는 그룹 저장 실패와 두 탭의 충돌, 기존 기록의 루틴 연결과 취소, 참여자 역할 변경, 게스트 가입·기록·내보내기를 검사했다. 초대 가입에는 공유 동의가 필요하며, 내보낸 사람의 과거 기록은 보존해야 했다.

Unslop을 다시 사용해 반복 장식·불필요한 그래프·중복 설명을 덜어냈다. 사용한 제작자·원본·라이선스는 [출처 문서](../../THIRD_PARTY_NOTICES.md)에 남겼다. 검사 수치와 실행 방법, 화면은 [5차 개선 결과](../../docs/17_테일리_5차개선.md)에 정리했다.

## 아직 판단하지 않은 것

자동 검사와 개발자의 화면 확인은 실제 보호자의 반복 사용 평가가 아니다. 이번 결과를 사용 시간 단축이나 만족도 향상으로 포장하지 않았다. 현재는 로컬에서 구현·검증한 상태이며, 사용자가 완성본을 확인한 뒤 다음 수정을 결정한다. GitHub 업로드와 외부 배포는 하지 않았다.
