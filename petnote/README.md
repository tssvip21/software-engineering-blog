# 펫노트 (PetNote)

가족이 한 반려동물의 돌봄 기록과 일정을 공유하는 웹 서비스입니다. 급여 설정에 사료와 용량을 저장해 두면, 다음 식사부터 버튼 한 번으로 기록할 수 있습니다. 다른 보호자도 급여 기록을 열어 언제 누가 밥을 줬는지 확인할 수 있습니다.

## Docker로 실행하기

Docker Compose를 사용할 수 있는 PC에서 저장소를 내려받고, 저장소 최상위 폴더에서 실행하세요. 첫 실행에는 이미지를 내려받을 인터넷 연결이 필요합니다.

```sh
cd petnote
docker compose up -d --wait
```

1. [펫노트 열기](http://127.0.0.1:8096/)에서 **관리자로 보기 → 강아지**를 선택합니다. 시연 공간은 강아지와 고양이 두 개입니다. 오늘 화면에서 미리 설정된 급여를 한 번 기록하고, 전체 기록에서 방금 저장한 내용을 확인합니다.
2. 새 공간을 만들려면 첫 화면에서 **빈 계정으로 시작**을 선택합니다.
3. `docker compose ps`로 프런트엔드(Caddy), 백엔드(Django), DB(PostgreSQL)가 실행 중인지 확인합니다. [상태 확인 주소](http://127.0.0.1:8096/health/)에서 `status` 값이 `ok`이면 웹 요청이 정상 처리된 것입니다.

`docker compose down`으로 종료해도 기록은 해당 PC의 Docker 볼륨에 남습니다. 같은 폴더에서 다시 시작하면 기존 기록을 볼 수 있습니다.

## 완성도와 검증 결과

| 항목 | 확인한 내용 |
|---|---|
| 기능 | 급여·산책·체중 등 18개 기능을 선택할 수 있습니다. 가족이 남긴 기록의 조회·수정·취소, 루틴 완료, 기간별 통계를 지원합니다. |
| 화면 | PC는 사이드바, 모바일은 하단 탐색 메뉴를 사용합니다. 두 화면에서 같은 기록을 확인할 수 있습니다. [PC 화면](http://127.0.0.1:8096/?layout=desktop) · [모바일 화면](http://127.0.0.1:8096/?layout=mobile) · [자동 선택](http://127.0.0.1:8096/?layout=auto) |
| 속도 | 산책 기록 1,200건을 넣은 로컬 Docker 환경에서 오늘 화면의 DB 조회를 56회에서 24회로 줄였습니다. 서버 응답 시간 중앙값은 89.0ms에서 49.0ms로 줄었습니다. |
| 자동 검사 | SQLite와 Docker PostgreSQL에서 Django 테스트가 각각 486개 통과했습니다. Chromium 브라우저 검사 61개에서 빠른 기록, 초대, 모바일 탐색 등을 확인했습니다. |
| 기록 보존 | Docker 컨테이너 세 개를 재시작한 뒤 PostgreSQL에 저장된 기록 1,231건의 내용과 수정·취소 상태가 일치했습니다. |
| 사용자 테스트 | 실제 사용자 대상 테스트는 아직 진행하지 않았습니다. |
