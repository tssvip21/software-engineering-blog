# 모듈과 공통 활동 기록 구조

개인·공동 사용이 가능한 반려동물 공간과 공통 활동 기록을 기반에 두고, 산책·밥·간식은 각 활동에 필요한 정보를 추가하는 방식으로 설계한다. 기록은 모듈별 통계와 종합 상태 확인에 사용하며, 반려동물의 기본 분류와 비교 기준을 연결할 수 있게 한다. 다음 내용은 ERD와 구현 명세를 만들기 위한 구조 초안이다.

## 공통 기능과 개별 모듈

반려동물 정보와 기본 분류, 구성원 관리, 활동 기록, 루틴, 알림, 통계와 비교 기준의 공통 처리는 서비스의 기본 기능으로 둔다. 개별 모듈은 해당 활동의 입력 항목과 상세 화면, 모듈별 통계 항목을 정의한다. 종합 상태 화면은 여러 모듈의 집계 결과와 적용 가능한 기준을 모아 보여준다.

밥과 간식은 서로 다른 모듈이지만 같은 제품 정보를 참조하고 같은 영양 계산을 사용한다. 영양 합계는 현재 화면에 보이는 모듈이 아니라 실제 기록을 기준으로 계산한다.

종별 기본 구성은 반려동물을 처음 등록할 때 적용한다. 사용자가 변경한 설정을 다시 자동 설정으로 덮어쓰지 않는다.

## 기본 데이터 관계

회원과 반려동물은 구성원 정보를 통해 연결한다. 한 회원은 여러 반려동물 공간에 참여할 수 있고, 한 반려동물 공간에는 한 명 또는 여러 명이 참여할 수 있다. 개인 사용에서도 기록·루틴·통계를 사용할 수 있으며, 다른 사람을 초대하는 것은 선택이다.

반려동물마다 모듈 설정, 활동 기록, 루틴을 가진다. 모듈 설정에는 사용 여부와 표시 순서, 알림 설정을 저장한다. 활동 기록에는 어떤 모듈에서 발생한 활동인지 표시한다.

루틴은 여러 항목으로 구성한다. 각 항목은 산책이나 밥 같은 활동 종류와 필요한 기본 입력값을 참조한다. 반복 루틴의 정의와 날짜별 실행 내역은 구분한다.

급여 기록은 제품 정보를 참조한다. 제품의 칼로리나 성분 정보가 나중에 수정되더라도 과거 계산의 기준을 확인할 수 있도록 사용한 값과 출처를 기록에 남기는 방향으로 설계한다.

## 기본 분류와 비교 기준의 구조

반려동물에는 종과 해당 종에서 사용하는 체격 등의 기본 분류를 연결한다. 이번 학기는 세부 품종보다 소형·중형·대형 정도의 구분을 우선한다. 분류 항목과 선택지는 동물 종류별로 둘 수 있도록 하고, 특정 종의 구분이나 수치 기준을 모든 동물에 공통 적용하지 않는다.

비교 기준에는 대상 종·분류, 비교할 지표, 단위, 적용 기간, 기준값 또는 범위, 출처와 확인 시점을 둘 수 있도록 설계한다. 보호자가 정한 목표와 외부 근거에서 가져온 기준도 구분한다. 구체적인 기준값과 테이블 구성은 아직 정하지 않았다.

통계는 유효한 활동 기록에서 계산하고, 비교는 집계된 지표와 적용 가능한 기준을 연결하는 단계로 분리한다. 기본 분류를 등록했다고 모든 비교값이 자동으로 생기지는 않는다. 적용 기준이 없거나 여러 기준이 겹칠 때는 임의로 선택해 판정하지 않으며, 선택 규칙은 데이터 설계에서 정한다.

## 활동 기록의 공통 항목

- 활동을 식별하는 번호와 대상 반려동물
- 활동 종류, 수행자, 기록 작성자
- 예정 시간과 실제 시작·종료 또는 급여 시간
- 예정·진행 중·완료 상태
- 메모, 작성·수정 시간과 수정 이력

산책 상세에는 거리와 소요 시간, 측정 방식을 추가한다. 밥·간식 상세에는 제품, 제공량, 확인 가능한 실제 섭취량, 단위와 계산에 사용한 제품 정보를 추가한다. 활동별로 필요하지 않은 항목은 요구하지 않는다.

## 루틴과 활동 연결

반복 설정으로 특정 날짜의 루틴 실행 내역을 만든다. 그날의 각 항목에 실제 활동 기록을 연결하면 완료로 표시한다. 예정만 된 항목은 급여량이나 산책량에 포함하지 않는다.

루틴에서 완료를 입력하면 활동 기록을 한 번 생성하고 해당 항목에 연결한다. 모듈에서 먼저 기록한 경우에는 반려동물, 활동 종류, 시간 등을 바탕으로 연결 후보를 보여주고 확인하게 한다.

루틴이 기록을 별도로 복사해서 저장하지 않도록 한다. 통계는 활동 기록을 기준으로 한 번만 집계한다. 같은 완료 요청이 반복되거나 두 구성원이 동시에 같은 항목을 완료해도 같은 활동이 중복 저장되지 않도록 구현 단계에서 처리한다.

## 모듈 비활성화와 기록 변경

모듈을 꺼도 과거 활동과 영양 합계는 유지한다. 해당 모듈을 사용하는 반복 루틴 항목은 일시 중지로 표시하고, 관련 새 알림을 중단한다. 기록을 완료한 것처럼 바꾸지 않는다.

급여량이나 산책 시간이 수정되면 같은 기록을 사용하는 하루 요약과 통계도 갱신한다. 잘못된 기록을 취소할 때는 집계에서 제외하고 수정 이력을 남긴다. 상세 편집 권한은 구성원 권한 설계에서 정한다.

## 예시 흐름

사용자가 ‘저녁 돌봄’의 밥 항목에서 사료와 양을 입력한다. 공통 활동 기록과 급여 상세를 저장하고, 그 기록을 오늘의 루틴 항목에 연결한다. 밥 모듈, 오늘 화면, 영양 합계와 종합 상태 화면이 같은 기록을 참조한다. 공동 사용에서는 구성원이 같은 기록과 진행 상태를 확인한다.

사용자가 밥 모듈에서 양을 수정하면 루틴 연결은 유지되고 영양 합계와 그 합계를 사용하는 비교 결과가 새 값에 맞춰 갱신된다. 새 급여 기록을 추가로 만들지 않는다.

## 다음 설계에서 정할 사항

실제 테이블과 필드 이름, 회원 인증 방식, 초대 방식, 구성원의 수정 권한, 날짜 기준과 시간대, 활동 상세의 저장 방식, 종별 기본 분류와 비교 기준의 연결 방식을 ERD 단계에서 정한다. 첫 설계는 현재 모듈과 기본 분류·비교 구조를 구현할 수 있을 만큼 구체화한다. 세부 품종별 분석과 사용자가 모듈을 직접 제작하는 별도 확장 시스템은 이번 학기 범위에 포함하지 않는다.
