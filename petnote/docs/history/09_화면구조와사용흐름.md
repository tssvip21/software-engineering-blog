# 테일리 2차 화면 구조와 사용 흐름

2026-11-04 설계. 외부 사이트를 참고해 구성과 사용 흐름을 검토했다. 화면을 먼저 역할별로 나누고, 14개 수정 항목을 하나의 기록 흐름에 연결한다. 이 문서는 설계 기준이며 완료 결과는 구현·검증 기록과 구분한다.

## 화면의 역할

|화면|먼저 보여줄 것|주요 행동|다음 화면|
|---|---|---|---|
|첫 진입|무엇을 기록하고 함께 보는지, 구분된 예시|계정으로 시작 / 초대로 참여|내 돌봄 공간|
|오늘|진행 중 활동, 시점이 된 활동, 루틴, 고정한 기록 동작|빠른 기록·완료·취소|필요할 때 상세 수정|
|돌봄 모듈|사용 중인 활동별 기능과 상태|바로 기록 / 주기 관리 / 상세 통계|선택한 활동 관리|
|모듈 상세|활동의 주요 입력, 주기, 최근 상태|빠른 기록 / 필요한 설정|필터된 전체 이력·통계|
|전체 기록|날짜·시간·작성자·핵심 내용|검색·필터·상세 확인|개별 기록 수정·취소|
|루틴|이름·예정 시각·담당자와 가까운 실행 동작|빠른 기록 / 기존 기록 연결|같은 날짜의 일정 확인|
|통합 상태|여러 활동의 핵심 변화와 기록 범위|현재·7일 전·1개월 전 비교|해당 상세 통계|
|구성원·설정|참여자와 역할 / 방 정보·관리 설정|허용된 관리 작업|모듈 구성·제품·초대|

## 한 기록을 여러 화면에서 사용

빠른 기록도 기존 활동 저장 서비스를 사용한다. 오늘의 완료 피드백, 루틴 연결, 전체 이력, 개별 통계, 통합 상태에 같은 기록을 반영한다. 수정·취소도 같은 권한 검사와 변경 이력을 거친다. 별도의 가짜 완료 목록을 만들지 않는다.

시각·작성자는 이미 아는 값으로 준비하고, 설명·추가 측정·다른 수행자는 펼쳐 바꾼다. 최근 입력값은 명시적으로 선택한 경우에만 넣고 저장 전에 확인한다. 측정값이 없는 활동은 완료 여부만 남긴다. 체중·환경 측정과 투약 용량 등 의미에 필요한 값은 계속 확인한다.

## 활성화, 고정, 주기 안내

모듈 활성화는 사용 가능 여부이고, 오늘 고정은 자주 쓰는 입력 동작의 배치다. 주기 안내는 활동별 설정이다. 같은 위생 모듈에서도 양치와 목욕을 따로 설정한다. 일·주·달 간격과 첫 안내 날짜는 사용자가 정한다. 의료적 권장 주기는 임의로 넣지 않는다.

새 주기를 설정한 뒤 남긴 유효한 완료 기록부터 다음 안내일을 계산한다. 완료를 취소하면 남아 있는 완료 이력에서 다시 계산한다. 이번 안내 미루기와 반복 간격 변경은 구별한다. 모듈을 끄면 안내도 멈추지만 기록은 삭제하지 않는다.

## 생활 변화

기존 ‘발정·산란’ 중심 구성을 ‘생활 변화’로 확장한다. 성장, 먹이 변경, 생활환경·관리 방식의 변화를 날짜별로 남기고 관련 기간의 상태를 살펴보는 용도다. 종합 건강 점수나 인과관계를 자동 판정하지 않는다. 기존 내부 식별자와 기록은 보존하며 이전 형식의 항목도 상세에서 확인한다.

## 배치와 접근성

사이드바는 경계 드래그와 키보드로 너비를 바꾸고, 접은 뒤에는 본문에 남는 버튼으로 복원한다. 현재 방과 구성원 일부를 표시하고 전체 보기로 이어진다. 모바일에서는 좁은 화면을 가리는 탐색을 기본 접고 명확한 열기·닫기를 둔다.

모듈 구성은 ‘넣은 모듈’과 ‘전체 모듈’로 분리한다. 추가·제거·고정·드래그 정렬 결과를 저장하고, 실패나 다른 사람의 변경은 숨기지 않는다. 터치 핸들, 키보드 이동과 대체 위·아래 동작도 제공한다.

전체 기록은 날짜별로 묶은 읽기 폭의 이력, 루틴은 가까운 정보·행동 묶음, 통합 상태는 핵심 해석과 비교를 사용한다. 모든 화면을 같은 카드 격자로 통일하지 않는다.
