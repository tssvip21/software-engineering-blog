# 반려동물 돌봄 기능과 화면

개인이나 여러 사람이 필요한 모듈에서 쉽게 기록하고, 모인 기록을 통계와 종합 상태 확인에 활용할 수 있게 구성한다. 구성원을 초대하지 않아도 기본 기능을 사용할 수 있으며, 공동 사용에서는 같은 반려동물의 기록과 상태를 공유한다.

## 반려동물 공간과 구성원

반려동물의 이름, 종, 체격, 나이, 체중을 등록하고 전용 공간을 만든다. 혼자 사용하거나 함께 돌볼 구성원을 초대한다. 실제 대화 기능은 우선순위에 두지 않고 기록 공유를 먼저 만든다.

공간에 참여한 사람만 해당 반려동물의 기록을 볼 수 있게 한다. 초대 방식과 구성원별 수정 권한은 데이터 설계 단계에서 정한다. 기록에는 수행한 사람과 입력한 사람이 다를 수 있음을 고려한다.

## 기본 분류와 비교 기준

개·고양이·조류·파충류·양서류 등 종류를 구분하고, 해당 종류에 필요한 체격 등의 기본 분류를 설정할 수 있게 한다. 이번 학기는 세부 품종보다 소형·중형·대형 정도의 기본 분류를 우선하며, 동물 종류별 분류 항목은 따로 둘 수 있게 한다.

모듈별 기록의 합계와 추이는 기록에서 계산한다. 적절한 양이나 범위와 비교하는 기능은 해당 동물의 분류에 적용할 수 있는 기준이 있을 때 제공한다. 기준의 출처와 적용 대상을 함께 표시하고, 기준이 없는 항목은 기록·통계만 확인할 수 있게 한다. 구체적인 수치 기준은 추후 확인한다.

## 모듈 설정

종을 선택하면 기본 모듈을 자동으로 설정한다. 강아지는 산책·밥·간식, 고양이와 앵무새는 밥·간식을 초기 구성으로 사용한다. 사용자는 해당 반려동물 공간에서 모듈을 켜고 끄거나 순서를 바꿀 수 있다. 케이지 청소·훈련 등의 화면 예시는 이후 추가할 모듈을 설명하며, 모든 종별 전문 모듈의 완성을 이번 학기 범위로 삼지는 않는다.

모듈을 끄면 새 활동을 권하는 알림을 중단하고 기본 화면에서 숨긴다. 기존 기록은 남기며, 이미 입력한 밥과 간식은 영양 합계에서 빠지지 않게 한다.

## 산책

산책 담당자와 시작·종료 시간, 소요 시간, 거리를 기록한다. 진행 중에는 해당 공간에 ‘산책 중’ 상태를 보여주고, 공동 사용 시 구성원도 확인한다. 첫 구현은 시간과 거리의 직접 입력을 지원하고, GPS 기록은 이후 구현 순서로 제안한다.

하루·주간·월간 산책 횟수와 총거리, 총시간, 평균 시간을 확인한다. 소모 칼로리는 적용 가능한 계산 근거를 확인한 뒤 참고용 추정치로 추가한다.

## 밥

급여한 사람, 시간, 제품, 양을 기록한다. 아침·저녁 등 예정된 식사와 연결해 완료 여부를 보여주고, 추가 급여 전 최근 기록을 확인하게 한다.

제공한 양과 실제 먹은 양을 구분할 수 있도록 설계한다. 실제 섭취량을 모르는 경우에는 제공량을 바탕으로 계산했다는 사실을 표시한다.

## 간식과 영양 합계

간식의 제품, 양, 시간, 담당자를 기록한다. 해당 반려동물에 입력한 기록을 합쳐 오늘 먹인 간식의 횟수와 양을 보여준다.

밥과 간식의 예상 칼로리는 미리 등록된 제품 영양 정보와 급여량을 이용해 하나의 하루 합계로 계산한다. 성분은 제품 정보가 있고 단위를 맞출 수 있는 항목만 계산한다. 없는 값은 미확인으로 표시한다. 계산과 비교 기준은 [제품 정보와 계산](04_제품정보와계산.md)에 정리한다.

## 루틴

활성화된 모듈의 활동을 골라 하나의 루틴을 만든다. 루틴 이름, 반복 요일, 예정 시간, 담당자, 항목 순서를 설정한다. 예를 들어 ‘저녁 돌봄’에 밥과 산책을 넣을 수 있다.

실행 화면은 예정·진행 중·완료 상태를 보여준다. 완료 버튼은 공통 활동 기록을 생성하거나 기존 기록에 연결한다. 이미 기록한 활동을 다시 복사해 생성하지 않는다.

## 공유와 알림

활동의 진행 상태와 완료 기록을 같은 공간에 반영한다. 이미 처리한 식사나 진행 중인 산책이 있으면 최근 기록을 보여주고 추가 활동이 맞는지 확인하게 한다. 추가 돌봄이 필요한 경우에는 기록할 수 있다.

예정 시간이 지난 항목은 완료 기록이 없는 일정으로 알린다. 앱 밖에서 수행했을 가능성이 있으므로 실제 미수행으로 단정하지 않는다. 첫 버전의 알림은 서비스 내부 표시부터 구현하고, 외부 알림 방식은 후속 검토한다.

## 통계

산책은 횟수·거리·시간을, 밥과 간식은 급여 횟수·양·예상 칼로리를 기간별로 보여준다. 제품별 기록과 날짜별 변화도 확인할 수 있게 한다.

루틴 통계는 예정 항목 중 완료 기록이 연결된 비율을 보여준다. 기록이 없는 날과 실제 활동량이 0인 날을 구분한다. 공동 사용의 구성원별 기록은 담당 내역을 확인하는 용도로 사용한다.

## 종합 상태 확인

여러 모듈에서 계산한 급여량·활동량·영양 합계와 기간별 변화, 루틴 완료 상태를 한곳에 모아 확인한다. 적용 가능한 분류별 기준이 등록된 지표는 그 기준과 비교하고, 기준이 없거나 정보가 부족한 지표는 그 상태를 구분한다. 종합 상태는 확인 가능한 관리 지표를 모아 보여주는 기능이며, 근거 없는 종합 점수를 만들지는 않는다.

## 화면 구성

반려동물 선택 화면에서 혼자 관리하거나 공동으로 참여 중인 공간을 고른다. 해당 공간의 오늘 화면에는 진행 중인 활동, 오늘의 루틴, 최근 기록과 남은 일정, 주요 관리 지표의 요약을 배치한다.

모듈 화면에서는 활동을 입력하고 상세 내역을 확인한다. 루틴 화면에서는 반복 일정을 만들고 실행하며, 통계·종합 상태 화면에서는 기간별 변화와 분류별 기준에 따른 비교 결과를 확인한다. 설정 화면에서는 반려동물 정보와 기본 분류, 구성원, 모듈과 알림을 관리한다.
