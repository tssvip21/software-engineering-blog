# 펫노트 프로젝트 딕셔너리

## 기능 범위

사용자가 선택하는 돌봄 기능은 18개다. 예전 기록을 읽기 위해 남겨 둔 두 종류(미용, 생활 변화)까지 포함하면 코드에 등록된 기록 종류는 20개다. 실제 목록은 `care/modules.py`의 `SELECTABLE_MODULES`에서 확인할 수 있다.

| 사용 흐름 | 기능 |
|---|---|
| 먹이와 활동 기록 | 먹이·급여, 간식, 물 관리, 배변, 산책, 놀이, 훈련 |
| 건강과 생활 관찰 | 체중, 위생·손질, 투약, 특이사항 메모, 병원·예방접종, 수면·휴식, 사육환경, 탈피·털갈이 |
| 용품과 비용 관리 | 용품·재고, 지출 |

인증, 권한, 루틴, 통계는 여러 돌봄 기능이 함께 쓰는 코드다. 화면·입력 처리는 `care/care_views.py`, 공간 설정은 `care/workspace.py`, 통계 계산과 표시 형식은 `care/reporting/`에서 찾을 수 있다.

## 실행 구조

브라우저가 보낸 요청은 Docker의 `frontend`(Caddy)를 거친다. Caddy는 CSS·JS·글꼴을 직접 보내고, 나머지는 `backend`(Django)에 넘긴다. Django가 HTML을 만들고 `db`(PostgreSQL)에 기록한다. Docker 시연은 전용 PostgreSQL을 쓰고, Python으로 단독 실행하는 시연은 SQLite를 쓴다.

| 위치 | 역할 |
|---|---|
| `compose.yaml`, `Dockerfile`, `deploy/` | 세 컨테이너, 실행 순서, 정적 파일, 상태 검사 |
| `config/`, `care/urls.py` | DB·세션 설정, 주소와 처리 함수 연결 |
| `templates/`, `static/care/` | 브라우저에 보이는 화면, 버튼 동작, 스타일 |
| `care/forms.py`, `care/profile_settings.py`, `care/supplies.py` | 기록·프로필·물품 입력 검사 |
| `care/services.py`, `care/record_actions.py`, `care/routine_completion.py` | 공간별 권한, 저장, 재시도, 루틴 완료 |
| `care/models.py`, `care/migrations/` | 저장 항목과 관계, DB 구조 변경 이력 |
| `care/tests/`, `scripts/` | 서버 테스트, 실행 도구, 브라우저 검사 |

## 사용 흐름

아래에서 `R`은 `/rooms/<공간 ID>`다. 한 공간이 반려동물 한 마리를 나타낸다. 주소에 들어가는 ID와 별도로 서버가 현재 사용자의 공간 참여 여부와 역할을 확인한다.

| 사용자가 하는 일 | 주소와 방식 | 처리 코드 | 주요 저장 항목과 권한 |
|---|---|---|---|
| 로그인·내 공간 목록 | POST `/auth/google/start/`, GET 콜백·`/` | auth, views.home | GoogleAccount와 사용자, 활성 Membership. 개인 세션으로 목록 조회 |
| 반려동물 등록 | GET·POST `/rooms/new/` | views.room_new, services.create_room | Room, 방장 Membership, 기본 ModuleSetting과 설정 이력. 로그인 필요 |
| 구성원 초대·참여 | POST `R/invitations/new/`, `/join/preview/`, `/join/confirm/` | views, services | Invitation의 만료·사용 조건 확인 후 Membership 생성 |
| 오늘 화면·빠른 기록 | GET `R/`, POST `R/actions/` | care_views, record_actions | Activity에 활동·시간·상태·입력값 저장. ActionReceipt로 같은 작업의 재시도 구분 |
| 직접 입력·수정·취소 | GET·POST `R/modules/<활동>/new/`, `R/records/<기록>/edit/`, POST 취소 | views, forms, services | Activity, ActivityRevision. 활성 기능·작성 권한·수정 버전 확인 |
| 기록 검색·조회 | GET `R/records/`, `R/records/<기록>/` | browsing.records, views.record_detail | 공간과 공개 범위 안에서 분류·검색어·기간·작성자·상태로 조회 |
| 일정 등록·완료 | GET·POST `R/routines/new/`, `R/routines/items/<항목>/complete/` | views.routine_edit, routine_completion | Routine과 RoutineItem, 시점별 RoutineVersion, 날짜별 RoutineRun 및 연결된 Activity |
| 물품·재고 | GET `R/supplies/`, GET·POST `R/products/new/` | workspace, supplies, inventory_ledger | Product의 단위·포장 정보와 Activity의 입출고·사용량으로 잔량 계산 |
| 측정값 비교 | GET `R/overview/`, `R/modules/<활동>/statistics/` | care_views, module_reports, stats | 권한이 있는 기록의 단위·기간별 집계 |
| 프로필·공간 설정 | GET·POST `R/settings/`, `R/preferences/` | workspace, profile_settings | Room의 공동 설정과 Membership의 개인 설정. 민감 기록 공개 여부는 방장이 변경 |

운영의 Google 로그인, PC의 시연 계정, 자동 검사의 가상 사용자는 서로 다른 로그인 경로다. 시연 계정 선택기는 PC의 로컬 시연 모드에만 표시된다.
