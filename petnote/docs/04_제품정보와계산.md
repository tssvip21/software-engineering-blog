# 제품 영양 정보와 통계·비교 기준

미리 등록한 제품 영양 정보와 급여량을 기준으로 예상 칼로리를 계산하고, 확인 가능한 성분만 합산한다. 이 결과를 다른 모듈의 통계와 함께 종합 상태 확인에 활용한다. 제품 정보는 직접 등록을 우선 구현하고 자동 조회는 데이터 확보 가능성을 확인한 뒤 연결한다. 실제 계산 기능과 제품 조회 연동은 구현 전이다.

## 제품 정보 API 후보

Open Pet Food Facts는 반려동물 먹이 제품을 다루는 API 후보이다. 공식 문서는 바코드 기반 조회와 원재료·영양정보 등 제품 데이터의 활용 방법을 안내하며, 대부분의 작업에 Open Food Facts API 문서를 함께 사용하도록 설명한다.

국내 판매 사료와 간식, 앵무새 먹이의 등록 범위와 칼로리·성분의 누락 정도는 별도 확인이 필요하다. 실제 사용할 제품을 조회해 충분한 정보가 있는지 확인한 뒤 연동 범위를 정한다.

제품 조회가 실패하거나 필수 값이 없으면 직접 등록하거나 보완할 수 있게 한다. 포장지 사진에서 글자를 읽어 입력을 돕는 기능은 이후 확장 후보이며, 첫 버전은 직접 입력을 지원한다.

## 제품에 저장할 정보

제품명, 제조사, 대상 동물, 바코드, 내용량과 기준 단위를 저장한다. 칼로리는 kcal/kg, kcal/100g, 개당 kcal 등 원래 기준을 보존하고, 필요한 단위로 환산할 수 있을 때만 계산한다.

성분은 이름, 값, 단위와 기준량을 저장한다. 원재료 목록과 수치가 있는 영양성분은 구분한다. 수치가 없는 원재료 목록만으로 섭취한 영양소의 양을 계산하지 않는다.

API, 제조사 표시, 직접 입력 등 출처와 확인 시점을 함께 남긴다. 제품에서 표시한 최소·최대 보증값과 정확한 수치도 구분한다.

## 섭취량과 칼로리

실제 먹은 양을 확인할 수 있으면 그 양을 사용한다. 제공한 양만 아는 경우에는 제공량 기준 예상치로 표시한다. 먹이를 남기거나 여러 동물이 함께 먹었다면 제공량을 개체의 실제 섭취량으로 확정하지 않는다.

그램 기준 급여량과 제품 칼로리를 연결할 수 있는 경우 다음 관계로 계산한다.

`예상 칼로리 = 계산에 사용하는 양(g) × 제품 칼로리(kcal/g)`

하루 합계는 밥과 간식의 유효한 급여 기록을 합산한다. 예정된 식사와 취소한 기록은 제외하고, 모듈을 숨겨도 이미 완료한 기록은 포함한다.

개수로 입력한 간식은 개당 칼로리나 개당 무게가 있어야 계산할 수 있다. 환산 정보가 없으면 급여 기록을 저장하되 칼로리는 미확인으로 둔다. 일부 기록의 칼로리를 모를 때는 ‘확인된 칼로리 합계’임을 표시한다.

## 성분 합계와 분류별 비교 기준

같은 성분을 같은 기준과 단위로 환산할 수 있는 경우에만 합산한다. 최소값은 최소값으로, 최대값은 최대값으로 유지하며 이를 정확한 섭취량처럼 표시하지 않는다. 수치나 환산 정보가 없으면 미확인으로 둔다.

이번 학기에는 종·체격 등 기본 분류에 맞는 비교 기준을 등록하고 집계 결과에 연결할 수 있는 틀을 만든다. 리트리버·푸들 같은 세부 품종별 권장량을 모두 구현하는 범위는 아니다. 소형·중형·대형 등의 기본 구분을 우선하되, 동물 종류마다 적용 가능한 분류와 기준을 확인한다.

비교 기준의 구체적인 수치는 아직 정하지 않았다. 지표·단위·기간이 집계값과 맞고 대상 동물에 적용 가능한 근거를 확보한 항목부터 등록한다. 출처와 적용 대상, 확인 시점을 함께 남긴다. 분류만으로 권장량을 임의 생성하거나 한 동물의 기준을 다른 종류에 그대로 적용하지 않는다.

보호자가 설정한 하루 목표도 사용할 수 있지만, 분류별 근거 기준과는 구분해 표시한다. 적용 기준이 없으면 합계와 추이는 제공하되 기준 비교는 미확인으로 둔다. 종·나이·건강 상태를 종합한 세부 자동 권장량 계산은 후속 검토 사항이다.

## 산책 소모 칼로리

산책 횟수·거리·시간은 기록에서 집계한다. 소모 칼로리는 적용 대상과 조건이 명확한 계산 근거를 검토한 뒤 참고용 추정치로 제공한다. AAHA 지침의 걷기 관련 추정도 특정 속도 등의 조건을 전제로 하므로 거리만으로 모든 동물의 소모량을 확정하지 않는다.

개에게 적용하는 추정식을 고양이나 앵무새에 그대로 적용하지 않는다. 적용 가능한 근거가 없으면 칼로리를 표시하지 않고 활동 기록만 제공한다. 섭취 칼로리와 활동량은 함께 보여주되, 산책 추정 소모량을 추가 간식 허용량으로 자동 전환하지 않는다.

## 연동 전 확인할 사항

실제로 사용할 제품의 검색 성공 여부, 칼로리와 성분의 단위, 누락 항목, 종별 제품 범위, 데이터 이용 조건과 호출 제한을 확인한다. 화면에는 조회값의 출처와 사용자가 보완한 값을 구분해 남긴다. 비교 기준은 출처뿐 아니라 대상 종·분류, 단위와 기간이 현재 지표에 맞는지도 확인한다.
